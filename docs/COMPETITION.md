# Competition Brief -- Namma Space (Techfest IIT Bombay)

> Extracted from `docs/reference/namma spcae.pdf`. Focus: **Round 1** scope.

## Overall Problem

Build a pipeline that turns smartphone video of an indoor space into a
**3D Gaussian-splat web viewer** with first-person roaming, POI labelling,
and desktop navigation. AR navigation is a bonus.

---

## Round 1 -- 3D Reconstruction & Roaming (Online)

### Focus
SOP construction, 3D model building, and free-roaming in a web viewer.

### Dataset
Participants capture and map **their own home** (or a similarly accessible
indoor space) following their defined Standard Operating Procedure (SOP).

### Required Deliverables

Submit a **Round 1 Google Drive folder** link ("Anyone with the link can view")
containing:

| # | Deliverable | Details |
|---|-------------|---------|
| 1 | **Technical Abstract PDF** (max 5 pages) | System architecture, pipeline design, SOP construction details, technical approach. |
| 2 | **Proof of Concept & Web Viewer Link** | A document containing a working link to the web-viewer allowing free-roaming. |
| 3 | **Demonstration Video** (3--5 min) | Project scope, capture process, and a 3D web walkthrough demo. |
| 4 | **Code Repository** | Link/folder with setup instructions to reconstruct the model, plus sample data in a `test/` directory. |

### Evaluation Criteria (Round 1)

1. **SOP & Pipeline Soundness** -- clarity and robustness of the capture-to-viewer pipeline.
2. **Visual Quality & Model Fidelity** -- reconstruction quality.
3. **Web Viewer Performance** -- smooth, responsive free-roaming in the browser.
4. **Documentation & Video Clarity** -- how well everything is explained.

---

## Submission Rules

- All links in the Drive folder must be inside a **single organised PDF**
  named `Additional_Links_and_Prototypes.pdf`.
  Loose links or unorganised files **will not be reviewed** by judges.
- Drive folder permissions: **"Anyone with the link can view"**.
- Solutions must be the team's own original work. Open-source libraries and
  third-party tools are allowed if properly licensed and credited in the
  technical abstract.
- Queries go through the Techfest Competition Portal (Doubt section), **not**
  email. Official announcements via `aryan@techfest.org`.
